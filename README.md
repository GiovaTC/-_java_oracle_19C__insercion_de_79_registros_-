## 1. Objetivo

El programa realizará las siguientes operaciones:

1. Crear una tabla en Oracle 19c.
2. Crear un procedimiento almacenado llamado `INSERTAR_REGISTRO`.
3. Conectarse desde Java a Oracle mediante JDBC.
4. Ejecutar el procedimiento mediante `CallableStatement`.
5. Insertar **79 registros**.
6. Mostrar en consola el progreso de cada inserción.
7. Consultar al finalizar la cantidad total de registros.
8. Mostrar el resultado en consola.

```sql
        FECHA_REGISTRO
```


Código completo:

```java
package config;

import java.sql.Connection;
import java.sql.DriverManager;
import java.sql.SQLException;

public class ConexionOracle {

    private static final String URL =
            "jdbc:oracle:thin:@localhost:1521/orcl";

    private static final String USUARIO =
            "SYSTEM";

    private static final String PASSWORD =
            "oracle";

    public static Connection conectar() throws SQLException {

        return DriverManager.getConnection(
                URL,
                USUARIO,
                PASSWORD
        );
    }
}
```

# 12. Clase `Main.java`

Crear:

```text
Main.java
```

Código completo:

```java
import config.ConexionOracle;

import java.sql.CallableStatement;
import java.sql.Connection;
import java.sql.ResultSet;
import java.sql.Statement;

public class Main {

    public static void main(String[] args) {

        String sql = "{call INSERTAR_REGISTRO(?, ?)}";

        try (Connection conexion = ConexionOracle.conectar();
             CallableStatement procedimiento =
                     conexion.prepareCall(sql)) {

            System.out.println("======================================");
            System.out.println(" JAVA + ORACLE 19C");
            System.out.println(" INSERTANDO 79 REGISTROS");
            System.out.println("======================================");
            System.out.println();

            for (int i = 1; i <= 79; i++) {

                String nombre = "Registro " + i;

                int edad = 20 + (i % 40);

                procedimiento.setString(1, nombre);

                procedimiento.setInt(2, edad);

                procedimiento.execute();

                System.out.println(
                        "Registro " + i +
                        " insertado correctamente -> " +
                        nombre +
                        " | Edad: " + edad
                );
            }

            System.out.println();

            System.out.println("======================================");
            System.out.println(" PROCESO FINALIZADO");
            System.out.println("======================================");

            consultarRegistros(conexion);

        } catch (Exception e) {

            System.out.println();

            System.out.println(
                    "ERROR AL EJECUTAR EL PROCESO:"
            );

            e.printStackTrace();
        }
    }

    private static void consultarRegistros(
            Connection conexion) {

        String sql = """
                SELECT COUNT(*) AS TOTAL
                FROM REGISTROS_79
                """;

        try (Statement statement =
                     conexion.createStatement();

             ResultSet resultado =
                     statement.executeQuery(sql)) {

            if (resultado.next()) {

                int total =
                        resultado.getInt("TOTAL");

                System.out.println();

                System.out.println(
                        "Total de registros en Oracle: "
                                + total
                );
            }

        } catch (Exception e) {

            System.out.println(
                    "Error al consultar los registros."
            );

            e.printStackTrace();
        }
    }
}
```

# 13. Funcionamiento del `CallableStatement`

Los parámetros se establecen mediante:

```java
procedimiento.setString(1, nombre);

```

Finalmente se ejecuta:


# 28. Consideración importante sobre `COMMIT`

En este ejemplo, el procedimiento contiene:

```sql
COMMIT;
```

Por lo tanto, cada llamada al procedimiento confirma inmediatamente su inserción.

Esto funciona correctamente para un ejemplo básico.

Sin embargo, para un escenario real, especialmente cuando se procesan muchos registros, puede ser preferible controlar la transacción desde Java.

Por ejemplo:

```text
Java
  │
  ├── Registro 1
  ├── Registro 2
  ├── Registro 3
  ├── ...
  └── Registro 79
          │
          ▼
       COMMIT
```

De esta forma, Java puede decidir si:

```text
COMMIT
```

o:

```text
ROLLBACK
```

---

# 29. Alternativa recomendada para transacciones

En un escenario real se podría eliminar:

```sql
COMMIT;
```

del procedimiento:

```sql
CREATE OR REPLACE PROCEDURE INSERTAR_REGISTRO (
    P_NOMBRE IN VARCHAR2,
    P_EDAD IN NUMBER
)
AS
BEGIN

    INSERT INTO REGISTROS_79 (
        NOMBRE,
        EDAD,
        FECHA_REGISTRO
    )
    VALUES (
        P_NOMBRE,
        P_EDAD,
        SYSDATE
    );

END;
/
```

Y controlar la transacción desde Java.

Por ejemplo:

```java
conexion.setAutoCommit(false);

try {

    // Procesamiento de los 79 registros

    conexion.commit();

} catch (Exception e) {

    conexion.rollback();

}
```

Esto permite tener mayor control sobre el proceso.
